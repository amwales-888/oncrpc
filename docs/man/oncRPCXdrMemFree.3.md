# oncRPCXdrMemFree(3)

## NAME

oncRPCXdrMemFree - free a block through a stream's allocator

## SYNOPSIS

```c
#include <xdr.h>

void oncRPCXdrMemFree(oncRPCXdr *xdrs, void *ptr);
```

## DESCRIPTION

`oncRPCXdrMemFree()` releases `ptr` with the allocator the stream `xdrs`
was set up with. A `NULL` pointer is ignored.

Code generated by `oncrpcgen` uses it in free mode, for blocks it
allocated itself while decoding (such as the node of a linked list). A
hand-written XDR routine that allocates with
[oncRPCXdrArrayAlloc(3)](oncRPCXdrArrayAlloc.3.md) releases the block the
same way.

## EXAMPLE

A hand-written routine for an optional value, kept behind a pointer:

```c
#include <xdr.h>

int xdr_optional_u32(oncRPCXdr *xdrs, uint32_t **pp)
{
    oncRPCBool present = *pp != NULL;

    if (xdrs->op == ONCRPC_XDR_FREE) {
        oncRPCXdrMemFree(xdrs, *pp);
        *pp = NULL;
        return 1;
    }
    if (!oncRPCXdrBool(xdrs, &present))
        return 0;
    if (!present) {
        *pp = NULL;
        return 1;
    }
    if (xdrs->op == ONCRPC_XDR_DECODE &&
        (*pp = oncRPCXdrArrayAlloc(xdrs, 1, sizeof(uint32_t))) == NULL)
        return 0;
    return oncRPCXdrUint32(xdrs, *pp);
}
```

[oncRPCXdrPointer(3)](oncRPCXdrPointer.3.md) does the same for any type.
