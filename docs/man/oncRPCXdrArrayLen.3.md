# oncRPCXdrArrayLen(3)

## NAME

oncRPCXdrArrayLen - XDR routine for an array's element count

## SYNOPSIS

```c
#include <xdr.h>

int oncRPCXdrArrayLen(oncRPCXdr *xdrs, uint32_t *len, uint32_t max);
```

## DESCRIPTION

`oncRPCXdrArrayLen()` encodes or decodes the element count that begins a
variable-length array, and checks it:

- **Encode:** fails if `*len` is above `max`.
- **Decode:** fails if the count is above `max`, or above the number of
  bytes that remain. Every element takes at least one byte on the wire, so
  a larger count cannot be genuine; refusing it stops a peer from making
  the decoder allocate a huge array it never fills.
- **Free:** does nothing.

It is the building block that code generated by `oncrpcgen` uses for
arrays, together with
[oncRPCXdrArrayAlloc(3)](oncRPCXdrArrayAlloc.3.md).
[oncRPCXdrArray(3)](oncRPCXdrArray.3.md) does the whole job for
hand-written routines.

## RETURN VALUE

Non-zero on success, 0 on failure as described.

## EXAMPLE

An array decoded into storage the routine allocates itself:

```c
#include <xdr.h>

struct ids {
    uint32_t *val;
    uint32_t  len;
};

int xdr_ids(oncRPCXdr *xdrs, struct ids *ids)
{
    uint32_t i;

    if (!oncRPCXdrArrayLen(xdrs, &ids->len, 1000))
        return 0;
    if (xdrs->op == ONCRPC_XDR_DECODE && ids->len > 0 &&
        (ids->val = oncRPCXdrArrayAlloc(xdrs, ids->len, sizeof(uint32_t))) == NULL)
        return 0;
    if (xdrs->op != ONCRPC_XDR_FREE)
        for (i = 0; i < ids->len; i++)
            if (!oncRPCXdrUint32(xdrs, &ids->val[i]))
                return 0;
    if (xdrs->op == ONCRPC_XDR_FREE) {
        oncRPCXdrMemFree(xdrs, ids->val);
        ids->val = NULL;
        ids->len = 0;
    }
    return 1;
}
```
